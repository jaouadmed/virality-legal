# Privacy policy

Last updated: 17 November 2026

Virality Uploader is a personal tool run by its owner on their own computer. It uses the YouTube Data API only to upload the owner's own videos to the owner's own YouTube channels and to read the name of the connected channel.

## Data accessed

With the owner's permission (Google OAuth), the tool receives an access token for the scopes `youtube.upload` and `youtube.readonly`. The token is stored only on the owner's computer. No data about other people is collected, stored, shared or sold.

## Sharing

No data is shared with third parties. Videos are sent only to YouTube.

## YouTube API Services

This app uses YouTube API Services. By using it you agree to be bound by the [YouTube Terms of Service](https://www.youtube.com/t/terms). Google's handling of data is described in the [Google Privacy Policy](https://policies.google.com/privacy).

## Data retention and deletion

The only stored data is the OAuth refresh token and the IDs of videos the tool uploaded, kept in a local file on the owner's computer. They are deleted when access is revoked or when the owner deletes the local configuration, and in any case are not kept longer than needed to upload videos. Revoking access below stops all further API use immediately.

## Revoking access

Access can be revoked at any time at [myaccount.google.com/permissions](https://myaccount.google.com/permissions).

The tool's use of information received from Google APIs adheres to the [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy), including the Limited Use requirements. Uploaded videos are also subject to the [YouTube Terms of Service](https://www.youtube.com/t/terms) and [Google Privacy Policy](https://policies.google.com/privacy).
