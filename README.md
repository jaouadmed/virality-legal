# Virality Uploader

Virality Uploader is a private tool used by its owner to publish their own short educational animated videos (in Moroccan Darija) to their own YouTube channels. It is not offered to the public.

**This app uses YouTube API Services.** Uploads go through the official YouTube Data API v3.
